# Contributing

Thanks for helping improve Luma OCR.

## Before you start

- Check existing issues before opening a duplicate.
- For a bug report, include your Windows version, Python version, Tesseract version, selected OCR language, and the steps needed to reproduce it.
- Do not attach private images or documents to public issues. Use a synthetic or public-domain sample when an image is needed to reproduce a problem.

## Changes

1. Keep changes focused and explain the user problem they solve.
2. Preserve the app's local-first behavior.
3. Update README.md when setup, supported formats, exports, or user-facing behavior changes.
4. Keep Python dependencies in requirements.txt and avoid adding packages for features available in the standard library.
5. Include a concise summary of the change in your pull request.
